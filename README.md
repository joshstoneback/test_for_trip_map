# 50 States 50 Trails 50 Foods 50 Days
Testing for a [map](https://joshstoneback.github.io/test_for_trip_map/) visiting 50 trails and 50 foods in 50 states in 50 days (one day per state)

Logic currently exists for the continental 48 states and a feasible path has been found. The logic forces the end of the trip to happen midday in either Washington or Oregon, from where you could take a midday flight to Alaska. The R files used to find the [optimal route](routefinding.R) to [create the map](mapmaking.R), and to find the [distance matrix](https://github.com/joshstoneback/test_for_trip_map/blob/main/distancematrix.R) are included in this repo. Full spreadsheets containing route logic can be found [here](https://github.com/joshstoneback/test_for_trip_map/blob/main/Itinerary.xlsx). The 50 food locations came from [this list](https://www.foodnetwork.com/restaurants/packages/best-food-in-america/photos/most-iconic-food-united-states). The 50 trails were the top trail on AllTrails in each state as of a few years ago when I compiled them. That list can be found [here](https://www.alltrails.com/lists/top-in-each-state-6d011ac?u=i&sh=5aldud)
